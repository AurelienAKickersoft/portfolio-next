# Portfolio - Aurélien

Bienvenue sur le dépôt de mon portfolio personnel. Ce projet a été réalisé avec [Next.js](https://nextjs.org) pour présenter mon parcours, mes compétences et mes réalisations.

## Fonctionnalités

Le site est composé des sections suivantes :

- **Accueil** : Présentation générale.
- **À propos** : Informations sur mon profil et mon expérience.
- **Projets** : Galerie de mes projets réalisés, avec des pages détaillées pour chacun.
- **Formation** : Détails sur mon parcours éducatif et mes certifications.

## Technologies utilisées

- **Framework** : [Next.js](https://nextjs.org/)
- **Langage** : JavaScript / React
- **Styles** : CSS Modules

## Installation et Démarrage

Pour lancer le projet localement, suivez ces étapes :

1.  **Installer les dépendances** :

    ```bash
    npm install
    # ou
    yarn install
    # ou
    pnpm install
    # ou
    bun install
    ```

2.  **Lancer le serveur de développement** :

    ```bash
    npm run dev
    # ou
    yarn dev
    # ou
    pnpm dev
    # ou
    bun dev
    ```

3.  **Ouvrir le navigateur** :
    Rendez-vous sur [http://localhost:3000](http://localhost:3000) pour voir le résultat.
